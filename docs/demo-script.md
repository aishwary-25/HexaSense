# HexaSense demo script

## 30-second pitch

"HexaSense is a private on-device AI knowledge assistant for Snapdragon PCs. It lets you upload local documents, ask questions in natural language, and get grounded answers from your own files without sending data to the cloud. It also supports private memory control, so sensitive files can be forgotten and removed from the system."

## Full demo

### Step 1: Open the app
- Launch HexaSense on a local Windows PC with Snapdragon X Elite.
- Show the upload area.

### Step 2: Upload sample docs
- Add a contract, notes, and research file.
- Show that the app redacts obvious email or sensitive values.

### Step 3: Ask a question
- Prompt: "What did the client say about the launch timeline?"
- The app retrieves relevant chunks.

### Step 4: Show answer grounding
- The answer includes quote snippets from the local text.
- Explain that the system only answers from the indexed local store.

### Step 5: Trigger forget mode
- Remove a file from the document set.
- Ask the same question again.
- Show that the removed file is no longer part of the answer.

### Step 6: Close with value prop
- Privacy-first local AI
- On-device processing
- Data retention control
- Works well on Snapdragon hardware
