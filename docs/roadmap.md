# HexaSense roadmap

## Phase 1: MVP (72h target)
- file upload
- basic parsing
- local retrieval
- grounded local answer generation
- file delete / forget workflow
- demo polish

## Phase 2: Privacy enhancements
- PII detection and redaction review
- user-configured sensitivity filters
- encrypted memory option

## Phase 3: Snapdragon optimization
- benchmark with different local model sizes
- optimize chunk size and retrieval latency
- test NPU acceleration strategies

## Phase 4: Productization
- richer UI
- Windows packaging
- export/import of memory index
- enterprise-ready indexing workflows
